┌┐└┘ ┤homelab├

A small self-hosted setup that I run myself, built around one Proxmox server.

Proxmox host · each service in its own LXC container (dns, media, git)

  • Pi-hole — network-wide DNS and ad blocker
    • runs in its own LXC container
    • Unbound added as the recursive resolver behind it, so names are resolved without a public DNS provider
  • Media stack — Seerr, Radarr, Sonarr, qBittorrent, Jellyfin
    • Seerr is where I browse and request movies and series
    • Radarr and Sonarr manage the library behind it, qBittorrent handles the downloads
    • Jellyfin streams the library to my devices
  • Gitea — self-hosted git
    • hosts the repository of my engineering thesis
    • the thesis is written as code in Typst
